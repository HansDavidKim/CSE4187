## 액터 개요

| 액터명 | 유형 | 설명 |
| --- | --- | --- |
| 모델 담당자 | 사용자 | 실험 데이터와 기준 주를 지정하여 학습 데이터셋을 생성한다. Uplift 모델의 학습과 성능 평가를 실행하고, 비교 결과를 바탕으로 예측에 사용할 모델을 결정한다. |
| 마케팅 담당자 | 사용자 | 대상 고객에 대한 쿠폰 효과 예측을 요청한다. 고객별 Uplift Score와 반응 세그먼트를 확인하고, 쿠폰 발송 대상 검토에 사용할 분석 결과를 내보낸다. |
| 고객 행동 시뮬레이터 | 시스템 | Uplift 서브시스템의 요청에 따라 실험 고객 목록, 고객별 Treatment/Control 배정, 고객별 주간 합계(방문·구매 등)를 제공한다. 배정 이후 활동이 없는 고객도 실험 고객 목록에 포함한다. |

모델 담당자와 마케팅 담당자는 역할 구분이므로 한 사람이 두 역할을 수행해도 된다.

## 유스케이스 개요

| 유스케이스명 | 설명 |
| --- | --- |
| **UC-01. 학습 데이터셋 생성** | 모델 담당자가 실험과 기준 주를 지정하면, 시뮬레이터의 고객 목록과 고객별 주간 합계를 이용하여 고객별 피처·Treatment·정답을 결합한 학습 데이터셋을 생성한다. 개입 전 12주 기록으로 필수 피처를 계산하고, 이후 4주 구매 여부로 정답을 생성한다. 미래 관측 기간이 완전히 확보된 고객만 학습 대상으로 포함한다. |
| **UC-02. Uplift 모델 학습** | 모델 담당자가 학습 데이터셋과 학습 설정을 지정하면, 개입 전 피처와 Treatment 및 정답을 이용하여 Uplift 모델을 학습하고 저장한다. 프로젝트 요구사항에 따라 최소 두 가지 방법을 학습하여 비교할 수 있도록 한다. |
| **UC-03. Uplift 모델 성능 평가** | 모델 담당자가 학습된 모델과 별도의 평가 데이터를 지정하면, Qini Curve 또는 Uplift Curve와 평가 결과를 제공한다. 모델별 성능을 비교하여 사용할 모델을 결정할 수 있도록 한다. |
| **UC-04. 고객별 쿠폰 효과 예측** | 마케팅 담당자가 대상 고객과 기준 주를 지정하면, 학습된 모델과 개입 전 기록을 이용하여 쿠폰 발송 시 유지 확률과 미발송 시 유지 확률을 예측한다. 두 확률의 차이를 고객별 Uplift Score로 제공한다. |
| **UC-05. 고객 반응 세그먼트 조회** | 마케팅 담당자에게 Uplift Score와 미발송 시 유지 확률을 기준으로 분류한 Persuadables, Sure Things, Lost Causes, Sleeping Dogs 결과를 제공한다. 세그먼트별 고객 수·비율·평균 Uplift와 고객 목록을 조회할 수 있도록 한다. |
| **UC-06. 분석 결과 내보내기** | 마케팅 담당자가 분석 결과를 선택하면, 고객 ID·기준 주·발송 및 미발송 시 유지 확률·Uplift Score·세그먼트를 CSV로 내보낸다. 후속 리텐션 전략과 예산 최적화에서 활용할 수 있도록 한다. |

세그먼트는 모델의 추정 결과에 따른 분류이며, 시뮬레이터 내부의 실제 반응 유형과 구분한다.
