\section{서론}
쿠폰 발송은 현재 구매뿐 아니라 다음 방문시점과 이탈확률을 바꿀 수 있다. 실제
사용자에게 여러 정책을 장기간 적용하는 방법은 비용이 크며, 오프라인 로그에는
선택되지 않은 행동의 결과가 없다. 행동 로그와 쿠폰 로그가 서로 다른 서비스에서
수집되었다면 사용자 식별자와 행동공간도 일치하지 않는다.

본 연구의 핵심은 이를 하나의 인과추정 문제로 포장하지 않고 세 층으로 분리하는
것이다. 첫째, 관측 시퀀스에서 무쿠폰 행동과 세션 복귀를 학습한다. 둘째, 공통
과거행동 특징으로 도메인별 집단을 정렬한다. 셋째, Tianchi의 비무작위 수령 차이는
공개된 합성 uplift 가정으로만 주입한다. 그 결과 쿠폰항을 제거하면 무쿠폰 생성기로
정확히 환원되는 모듈식 환경을 얻는다.

순차 추천~\cite{sun2019}은 행동표현에, uplift modeling~\cite{devriendt2018}은
증분반응에 집중한다. RecSim~\cite{ie2019}, RecoGym~\cite{rohde2018},
Virtual-Taobao~\cite{shi2019}는 정책평가용 사용자 환경을 제공한다. 본 연구는 세
공개 로그에서 공통 행동집단을 자동 정렬하고, 사용자 효용의 연속 이질성, 세션
간격, lifecycle, 비식별 쿠폰반응을 하나의 감사 가능한 파이프라인으로 연결한다.

\section{데이터와 대리군}
Cosmetics와 Electronics는 REES46 행동 로그~\cite{rees46}, 쿠폰 로그는 Alibaba
Tianchi O2O~\cite{tianchi}를 사용한다. Cosmetics의 행동은 \texttt{view},
\texttt{cart}, \texttt{remove}, \texttt{purchase}이며 명시적 세션이 있다.
Electronics에는 \texttt{remove}가 없고, Tianchi online 로그는 날짜별
\texttt{click}, \texttt{purchase}, 쿠폰 수령을 제공하되 일중 순서는 없다. 쿠폰
수령은 사용자 행동토큰이 아니라 정책 개입으로 분리한다.

교차 도메인 정렬에는 구매비중, 총 행동량, 활동일, 일별 행동량, 구매일 비중,
중앙간격, 최초·최종 구매위치, 탐색$\leftrightarrow$구매 전이와 지속성 등 13개
사전행동 특징만 사용한다. pooled robust scaling 후 각 사용자를 Cosmetics $K=4$
centroid에 최근접 배정한다. Electronics에서 대응이 불명확한 C1은 제외하고 C0,
C2, C3을 P0, P2, P3의 대리군으로 사용한다. 각 대리군 안에서 과거 구매여부와
과거 수령횟수를 exact match하고 propensity-logit 0.2 표준편차 caliper의 1:1
비복원 매칭을 적용한다. 결과 이후 정보는 배정에 사용하지 않는다.

\section{제안 방법}
\subsection{행동표현과 페르소나}
행동 사이에 세션경계 토큰을 넣고 15\%를 마스킹하여 원래 토큰을 복원한다.
16차원 토큰 임베딩과 방향별 hidden size 24의 양방향 GRU에서 48차원 사용자
표현 $z_u$를 얻는다. 저장된 $z_u$에 $K=4$ K-means를 적용하고, 얕은 조회군은
NEW와 CHURNING의 혼합상태로 분리하여 성숙 home persona를 P0, P2, P3으로 둔다.

\begin{algorithm}[t]
\caption{Masked GRU user representation}
\label{alg:gru}
\KwIn{chronological action sequences $D$}
\KwOut{stored user embeddings $Z$}
insert SESSION tokens into every $x_u\in D$\;
\ForEach{training batch $B$}{
  $\widetilde B\leftarrow\operatorname{Mask}(B,0.15)$\;
  $H\leftarrow\operatorname{BiGRU}(E(\widetilde B))$\;
  update $\psi$ by masked-token reconstruction\;
}
$z_u\leftarrow\operatorname{Std}([\overrightarrow h_u;\overleftarrow h_u])$\;
\end{algorithm}

\subsection{사용자별 효용과 세션간격}
행동 직전의 12개 특징은 절편, 세션 위치·경과시간·직전 이벤트 간격, 네 행동의
누적횟수와 직전행동 one-hot이다. 사용자 $u$의 즉시 효용과 선택확률은
\begin{equation}
r_u(s,a)=\theta_{u,a}^{\top}\phi(s),\qquad
\pi_u(a\mid s)=\frac{e^{r_u(s,a)}}{\sum_b e^{r_u(s,b)}}.
\end{equation}
Temperature는 1이며 각 특징에서 행동계수 합을 0으로 제약한다. persona prior를
먼저 학습하고 각 centroid 최근접 사용자 20명의 계수를 MAP으로 추정한다. 식별되는
네 행동$\times$12개 계수벡터에는 3성분 대각 GMM을 적합한다. 제곱·2변수 교차항을
포함한 78차원 모형은 pooled ablation에서 NLL을 0.648에서 0.600으로 낮췄으나,
개인별 표본에서의 안정성을 위해 생성기의 사용자 GMM은 12개 기본특징을 사용한다.

\begin{algorithm}[t]
\caption{Persona-conditioned MaxEnt IRL}
\label{alg:irl}
\KwIn{state--action decisions $D$, persona $c_u$}
\KwOut{coefficient mixture $q(\theta)$, gap model $q(\tau)$}
fit persona prior $\theta_c$ by multinomial MaxEnt\;
\ForEach{representative user $u$}{
  $\theta_u\leftarrow\operatorname{MAP}(D_u\mid\theta_{c_u})$\;
}
$q(\theta)\leftarrow\operatorname{GMM}(\{\theta_u\})$\;
fit $q(\tau\mid s_{\rm end})$ on eight gap tokens\;
\end{algorithm}

세션 종료 후 $\tau$는 0--1시간, 1--6시간, 6--24시간, 1--3일, 3--7일,
7--14일, 14--30일, NO\_RETURN\_30D 중 하나다. engagement, friction,
satiation, inactivity momentum, gap acceleration, habit strength를 과거 세션으로
재귀 갱신한다. 첫 간격은 학습평균 51.33시간으로 초기화하되 결측 지시자를 유지한다.
NEW$\rightarrow$home persona$\leftrightarrow$CHURNING 전이와 구매 후 30일
비복귀 종료를 별도로 모델링한다.

\subsection{도메인 GMM과 합성 uplift}
세 도메인의 13개 공통특징에 BIC와 최소성분크기 조건을 적용해 각각 4, 5, 6성분
대각 GMM을 학습한다. 먼저 도메인 GMM 성분을 뽑고 성분별 P0/P2/P3 조성에서
home persona를 뽑은 뒤 해당 persona의 효용계수를 샘플링한다. Electronics의
미관측 remove와 Tianchi의 미관측 cart/remove는 0 관측값으로 학습하지 않고
해당 도메인 행동공간에서 비활성화한다. 서로 다른 세션 단위의 중앙간격 비율은
제곱근 수축 후 $[0.5,4]$로 제한하여 시간측정 단위 자체가 행동차이로 과대전이되는
것을 막는다.

매칭된 비수령·수령 구매율을 $p_{c,0},p_{c,1}$라 하면 네 canonical type의 합성
비율은
\begin{equation}
\pi_c=(p_{c,0}p_{c,1},(1-p_{c,0})p_{c,1},
p_{c,0}(1-p_{c,1}),(1-p_{c,0})(1-p_{c,1})).
\end{equation}
순서는 sure thing, persuadable, sleeping dog, lost cause다. 이는 주변확률을
보존하는 최대엔트로피 독립결합이며 개인 유형의 식별값이 아니다. P0/P2/P3/P\_LT의
비율(\%)은 각각 $(2.82,19.50,9.82,67.85)$,
$(4.69,21.98,12.89,60.44)$, $(2.72,19.54,9.50,68.25)$,
$(10.49,23.86,20.05,45.60)$이다.

48차원 $z_u$와 절편에서 네 logit을 만드는 행렬 $W$를 $L_1=0.001$,
$L_2=0.01$로 학습하고 $c_u\sim\operatorname{Cat}(\operatorname{softmax}([1;z_u]^TW))$
로 샘플링한다. P\_LT에는 별도 logit offset을 학습한다. Persuadable과 sleeping
dog에 서로 반대 부호의 구매·복귀 offset을 주고, 반복 수령 노출은
\begin{equation}
E_t=\sqrt{\sum_{r<t}\left[\max\left(0,1-\lfloor(t-r)/7\rfloor/5\right)\right]^2}
\end{equation}
로 6주 안에 단조 감소시킨다. 무쿠폰 행동모형은 동결하고 $W$와 persona별
강도만 보정하므로 이는 continual learning이 아니라 sequential calibration이다.

\begin{algorithm}[t]
\caption{Sequential uplift calibration}
\label{alg:uplift}
\KwIn{frozen generator $G$, latent $Z$, targets $\pi^*,\Delta^*$}
\KwOut{canonical map $W^*$, uplift strength $\lambda^*$}
$W^*\leftarrow\arg\min_W\|\mathbb E_Z[\operatorname{softmax}([1;Z]^TW)]-\pi^*\|$\;
\ForEach{calibration iteration $k$}{
  $\widehat\Delta^{(k)}\leftarrow\operatorname{PairedRollout}(G,W^*,\lambda^{(k)})$\;
  update $\lambda^{(k)}$ toward $\Delta^*$\;
}
select the minimum-error iterate on independent users\;
\end{algorithm}

\section{실험}
합성 패널은 도메인별 1,000명·13주, 총 13,000 user-week이며 50:50 무작위
쿠폰행동과 8개 gap-token 횟수를 저장한다. 정책은 같은 규모에서 온라인 학습하고
독립 seed의 5,000명·52주에서 고정 평가한다. 관측상태는 persona, lifecycle,
최근 7/30일 행동, 마지막 세션·구매 이후 시간, 쿠폰노출과 발송가능 여부의 19개
과거정보다. Canonical type과 미래결과는 agent에서 숨긴다. UCB, TS, LinUCB,
LinTS~\cite{li2010,agrawal2013}, PPO~\cite{schulman2017}, discrete SAC~\cite{haarnoja2018}를
같은 사용자 seed로 비교한다.

판매 1회 가치는 1,000으로 고정한다. 비용모형 S는 발송마다 100을 차감한다.
비용모형 D는 발송비가 없고, 42일 내 미사용 쿠폰을 FIFO로 보관하여 첫 후속
구매에만 $\alpha=10\%$ 할인을 적용하며 이후 구매는 정상가격이다.

\section{결론}
본 연구는 공개 행동 로그에서 사용자 효용과 세션 lifecycle을 학습하고, 공통
특징정렬과 GMM으로 두 행동 도메인 및 쿠폰 도메인에 전이한 정책 시뮬레이터를
제시하였다. Tianchi 차이는 인과효과가 아니라 명시적 합성 보정값이며, canonical
type 역시 잠재결과 결합에 대한 가정이다. 따라서 표의 정책순위는 실제 배포효과의
증거가 아니라 비용·uplift·감쇠 가정에 조건부인 알고리즘 스트레스 테스트다.
후속연구에서는 무작위 쿠폰 로그로 반응모듈을 교체하고 비용 및 감쇠 민감도와
다중 seed 불확실성을 확대해야 한다.
