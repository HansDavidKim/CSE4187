## 기간 정의 주 단위 통일안

기준시점 `t0`는 서울 월요일 00:00이다. 굵게 표시한 값이 현재와 달라지는 항목이다.

| 모듈 | 항목 | 현재 | 주 단위 제안 |
|---|---|---|---|
| 시뮬레이터 | 전체 생성 | 24개월 (약 105주) | **104주** |
| | t0 이전 | 12개월 → 다음 월요일 (약 53주) | **52주** |
| | t0 이후 | 12개월 (365일) | **52주** |
| | 최소 고객 이력 | 0일 (일 단위 아무 값) | **13주** (91일) |
| | 적격 (최근 방문) | 28일 또는 30일 | **4주** |
| | 쿠폰 유효 | 28일 또는 30일 | **4주** |
| | 12개월 정답 `future_revenue_12m` | 달력 12개월 | **52주** |
| Uplift | 적격 | `[t0−28일, t0)` | `[t0−4주, t0)` |
| | 결과 | `[t0, t0+28일)` | `[t0, t0+4주)` |
| | 최근 창 피처 | 30일 | **4주** |
| | 변화량 피처 | 60일 | **8주** |
| | 방문 간격 피처 (F13·F14) | 90일 | **13주** |
| CLV | 입력 | `[t0−13주, t0)` | 그대로 |
| | 정답 | `[t0, t0+52주)` | 그대로 |

```
t0-52 ──────── t0-13 ── t0-8 ── t0-4 ── t0 ── t0+4 ─────────── t0+52
│ 가입 분포 구간 │← 최소 이력·CLV 입력·Uplift 간격 13주 →│
                         │← Uplift 변화량 8주 →│
                                 │← 적격·최근 4주 →│
                                                  │← Uplift 결과·쿠폰 4주 →│
                                                  │← CLV 정답 52주 ──────────────→│
```

- Uplift 피처 창(30·60·90일)은 설계서 v5 4.2 정의다. 바꾸려면 설계서 담당자와 합의하고 `_30d`, `_90d` 피처 이름도 함께 바꾼다.
- 시뮬레이터 항목은 시뮬레이터 담당자에게 수정 요청이 필요하다.

## 최종 전략 CLI·대시보드 출력 정보

### 고객별 CSV (`results/`)

| 컬럼 | 내용 |
|---|---|
| `customer_id` | 고객 ID |
| `churn_prob` | 이탈 확률 |
| `p0` | 미발송 시 4주 내 구매 확률 |
| `p1` | 발송 시 4주 내 구매 확률 |
| `uplift_score` | `p1 − p0` |
| `clv` | 예상 CLV |
| `segment` | 6세그먼트 |
| `priority_score` | 발송 우선순위 |
| `send` | 발송 여부 (0/1) |
| `expected_net_value` | 예상 순이득 |

### 요약 표

| 표 | 항목 |
|---|---|
| 세그먼트별 | 고객 수, 비율, 평균 CLV, 평균 이탈확률, 평균 uplift, 발송 수 |
| 예산 배분 | 총 예산, 발송 수, 예상 비용(발송비 + 할인), 예상 증분 매출, 예상 ROI |
| What-if | 예산 50%·100%·200%별 발송 수, 비용, 증분 매출, ROI |
| 전략 평가 | 군별 고객 수, 전환율, 이탈률, 고객당 순매출, 비용, ROI, A 대비 차이(95% 신뢰구간), 보정된 p값 |

### 대시보드 그래프

| 그래프 | 내용 |
|---|---|
| 이탈 위험 분포 | 이탈 확률 분포 |
| Uplift 4분면 분포 | Persuadables, Sure Things, Lost Causes, Sleeping Dogs |
| 6세그먼트 산점도 | x = uplift, y = CLV, 색 = 이탈확률 |
| Qini 곡선 | 모델별 Qini와 random targeting 비교 |
| 예산–ROI 곡선 | What-if 예산별 ROI |
| 전략별 주 지표 | 막대그래프, 신뢰구간 포함 |

- 미정: 전략 평가 방식. 시뮬레이터에 배정표 입력 기능을 요청할지, 1:1 무작위 데이터로 IPW 오프라인 평가를 할지 먼저 정한다.
