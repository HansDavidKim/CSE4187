# 프로젝트 WBS 및 업무분장표

- **팀에서 큰 분류를 합의합니다.**
- **각자가 담당 영역을 작업 패키지로 나눕니다.**
- **각 패키지의 WBS 사전을 작성합니다.**
- **팀에서 취합해 전체 WBS와 업무 분장표를 만듭니다**
- 업무분장표란 각 작업의 책임자 수행자 협조자를 지정
