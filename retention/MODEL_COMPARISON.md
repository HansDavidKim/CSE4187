# Retention 구현·모델 비교 결과

확정된 7종 입력이 모두 제공되는 경로로 구현하고, 같은 스키마의 테스트 전용 합성 데이터로 end-to-end smoke test를 완료했다. Cosmetics 원본을 가짜 주문·쿠폰 기록으로 변환하지 않았다.

## 검증 범위

- 프로젝트 `.venv`에 의존성 설치 및 `pip check` 통과. 정확한 설치 버전은 `requirements-lock.txt`에 기록.
- 입력: 고객 120명, 세션 3,512건, 이벤트 10,536건, 주문 1,374건, 주문 상품 2,744행, 쿠폰 1,446건, 사용 연결 709건.
- 고객·기준시각 표본 2,455개, 내부 피처 51개, 최종 테스트 268개 표본.
- 트리 3종 각각 5개 시간 fold·Optuna 2개 후보를 실행. 정답 구간이 다음 검증 시작을 넘는 학습 표본은 제외.
- LSTM·GRU는 같은 입력·은닉 크기·최대 epoch 예산을 사용하고, 외부 검증보다 앞선 별도 내부 시간 구간에서 Early Stopping.
- 기본 테스트 22개 통과: 시각 경계·미래 이벤트 차단·주문 상품 합산·쿠폰 연결·동일 timestamp 행 순서 불변·세션 복합 키·결측·모델 학습/패딩·CSV/Parquet 입력 등.
- 저장한 전체 추론 묶음 재로드 후 모든 모델 예측값 일치. 개별 LSTM·GRU `.pt`도 안전한 weights-only 로드 후 예측값 일치.
- 미래 기록이 없는 2024-10-01 추론: 120명 중 91명 점수 생성, 29명은 최근 방문 없음으로 제외 사유 반환. 전원 부적격인 시점도 오류 대신 상태 반환.

## 동일 테스트셋 비교

**아래는 합성 fixture에서 흐름을 검증한 결과다. 실데이터 정확도나 과제 AUC 기준 달성의 증거가 아니다.**

| 모델 | 공통 개발 검증 AUC | 테스트 AUC | 테스트 Brier |
| --- | --- | --- | --- |
| 상수 확률 | 0.5000 | 0.5000 | 0.1217 |
| 방문 최근성 로지스틱 | 0.7667 | 0.7428 | 0.1110 |
| LightGBM | 0.8790 | 0.9184 | 0.0854 |
| CatBoost | 0.8716 | 0.9358 | 0.0739 |
| XGBoost | 0.8407 | 0.8848 | 0.0908 |
| LSTM | 0.8469 | 0.9018 | 0.1064 |
| GRU | 0.8593 | 0.9044 | 0.1091 |
| LightGBM + GRU 평균 | 0.8741 | 0.9219 | 0.0921 |

개발 검증 기준 선택은 **LightGBM**이다. 테스트에서 CatBoost가 더 높더라도 테스트 결과를 보고 선택을 바꾸지 않았다. DL의 검증 성능은 GRU가 LSTM보다 높았고 앙상블 후보에는 GRU를 사용했지만, 앙상블 검증 점수는 단일 LightGBM을 넘지 못했다. 작은 단일 seed fixture의 순위를 실제 데이터의 일반적 우열로 해석하지 않는다.

확률 보정 그래프에는 과대 예측 경향이 있어 AUC와 확률의 신뢰도를 구분해야 한다. 실제 운영 확률로 사용하기 전 실데이터의 독립 개발 구간에서 보정을 검토한다. 이번 테스트셋으로 보정기를 학습하지 않았다.

## 논문·요구사항 대조

| 근거 | 구현에서 반영한 내용 |
| --- | --- |
| 확정 Feature 문서 | 7종 입력만 사용. 시뮬레이터 내부 숨은 값은 입력에서 제외 |
| 과제 피처 요구사항 | RFM·변화 5종·세션 품질·구매 주기·시간대·여정·시퀀스 요약, 51개 정의·산출 |
| 과제 ML 요구사항 | 트리 최소 2종을 넘어 3종 비교, 불균형 가중치, 5-fold·튜닝·SHAP·임계값 분석 |
| 과제 DL 요구사항 및 추가 요청 | 표준 PyTorch LSTM·GRU, 임베딩·패딩·Early Stopping, 같은 테스트에서 ML/DL·앙상블 비교 |
| 논문 §3.3 | 내부 합성 uplift·canonical type을 학습용 관측 피처나 실제 인과효과로 사용하지 않음 |
| 논문 §4 | 10% 쿠폰·구매 시 사용 관계를 구분. 할인율 최적화나 환불 기능을 임의로 추가하지 않음 |
| 변경 범위 | 소스·설정·보고서는 `retention/`, 패키지는 요청한 `.venv`에만 설치. 공용 docs/results·시뮬레이터 등은 수정하지 않음 |

대규모 실데이터 처리량은 아직 측정하지 않았다. 현재 구현은 필요한 컬럼을 읽은 뒤 메모리에서 피처를 계산한다. 수집 종료·누락 가정, 실제 기록 기간, 충분한 시간 fold를 실제 입력에 맞춰 설정해야 한다. 처치별 인과 예측과 T/X/H 학습은 별도 Uplift 연동 범위다.
